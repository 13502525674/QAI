物理AI助手外挂知识库（专业严谨版）

说明：本知识库适配物理AI助手外挂使用，涵盖初中、高中核心物理知识点，兼顾基础概念、公式推导、易错点辨析，内容严谨规范，格式统一，可直接用于AI检索匹配；所有公式标注适用条件，单位统一采用国际单位制（SI），模糊知识点明确标注适用范围，避免歧义。

一、力学（核心模块）

1.1 基础概念

1. 力（F）：物体对物体的作用，不能脱离物体独立存在；单位：牛顿（N），1N=1kg·m/s²。

2. 力的三要素：大小、方向、作用点，三者共同决定力的作用效果；力的合成遵循平行四边形定则（同向相加，反向相减，互成角度用平行四边形定则合成）。

3. 重力（G）：地球对物体的吸引产生的力，方向竖直向下（指向地心）；重力的等效作用点为重心（形状规则、质量分布均匀的物体，重心在几何中心）。

4. 弹力（F弹）：物体发生弹性形变时，对阻碍其形变的物体产生的作用力；产生条件：接触且发生弹性形变（塑性形变不产生弹力）。

5. 摩擦力（f）：两个相互接触的物体，发生相对运动或有相对运动趋势时，在接触面产生的阻碍相对运动的力；分为静摩擦力、滑动摩擦力、滚动摩擦力。

6. 惯性：物体保持原来运动状态（静止或匀速直线运动）的性质，是物体的固有属性，只与质量有关（质量越大，惯性越大），与速度无关；惯性不是力，不能说“惯性力”。

7. 平衡状态：物体处于静止或匀速直线运动状态，此时物体所受合力为0（合力F合=0）。

1.2 核心公式（含适用条件）

1. 重力公式：G = mg （适用条件：地球表面及近地空间，g为重力加速度，通常取g=9.8m/s²，粗略计算可取10m/s²；m为物体质量，单位kg）

2. 滑动摩擦力公式：f滑 = μN （适用条件：接触面粗糙、物体发生相对滑动；μ为动摩擦因数，与接触面材料、粗糙程度有关，无单位；N为接触面的正压力，单位N，水平面时N=G）

3. 静摩擦力：0 < f静 ≤ fmax（最大静摩擦力），无固定公式，由物体的受力平衡决定；fmax略大于滑动摩擦力，通常近似认为fmax=f滑。

4. 牛顿第一定律（惯性定律）：一切物体在没有受到力的作用时，总保持静止状态或匀速直线运动状态（理想化情况，实际中不受力的物体不存在）。

5. 牛顿第二定律：F合 = ma （适用条件：宏观、低速物体；F合为物体所受合力，单位N；m为质量，单位kg；a为加速度，单位m/s²，加速度方向与合力方向一致）

6. 牛顿第三定律：两个物体之间的作用力和反作用力，大小相等、方向相反、作用在同一条直线上，且同时产生、同时消失（作用力与反作用力作用在两个不同物体上，不能相互抵消）。

7. 功的公式：W = Fs cosθ （适用条件：恒力做功；W为功，单位焦耳（J），1J=1N·m；F为恒力大小，单位N；s为物体在力的方向上移动的距离，单位m；θ为F与s的夹角，θ=0°时W=Fs，θ=90°时W=0）

8. 功率公式：P = W/t （普适公式，P为功率，单位瓦特（W），1W=1J/s；W为总功，单位J；t为做功时间，单位s）；推导式：P = Fv cosθ（适用条件：恒力做功，v为瞬时速度时为瞬时功率，v为平均速度时为平均功率；θ为F与v的夹角）

9. 动能公式：Ek = 1/2 mv² （适用条件：宏观、低速物体；Ek为动能，单位J；m为质量，单位kg；v为瞬时速度，单位m/s）

10. 重力势能公式：Ep = mgh （适用条件：地球表面及近地空间，以参考平面为势能零点；Ep为重力势能，单位J；h为物体相对于参考平面的高度，单位m；参考平面可任意选取，通常取地面为参考平面）

11. 机械能守恒定律：E1 = E2（或Ek1 + Ep1 = Ek2 + Ep2） （适用条件：只有重力或弹力做功，其他力不做功或做功的代数和为0；机械能=动能+势能，势能包括重力势能和弹性势能）

12. 动量公式：p = mv （p为动量，单位kg·m/s；m为质量，v为瞬时速度，方向与速度方向一致）

13. 动量守恒定律：m1v1 + m2v2 = m1v1' + m2v2' （适用条件：系统不受外力或所受合外力为0；系统内力远大于外力时，可近似守恒（如碰撞、爆炸过程））

1.3 易错点辨析

1. 易错点1：重力方向“竖直向下”≠“垂直向下”，竖直向下指向地心，垂直向下仅垂直于接触面（如斜面上物体的重力方向仍竖直向下）。

2. 易错点2：动摩擦因数μ与正压力N无关，仅由接触面材料和粗糙程度决定；滑动摩擦力大小与接触面面积无关。

3. 易错点3：惯性不是力，不能说“物体受到惯性作用”，应说“物体具有惯性”；惯性大小与速度无关，只与质量有关。

4. 易错点4：功的正负判断：θ<90°时，力做正功；θ=90°时，力不做功；θ>90°时，力做负功（或物体克服该力做功）。

5. 易错点5：机械能守恒的条件是“只有重力或弹力做功”，并非“不受其他力”；若有摩擦力、拉力等其他力做功，机械能不守恒。

二、热学（基础模块）

2.1 基础概念

1. 温度（T）：表示物体冷热程度的物理量，单位：摄氏度（℃），国际单位制中为开尔文（K），换算关系：T(K) = t(℃) + 273.15。

2. 内能（U）：物体内所有分子动能和分子势能的总和，是物体的固有属性，一切物体在任何温度下都有内能；内能与温度、质量、状态（固、液、气）有关。

3. 热量（Q）：在热传递过程中，物体吸收或放出的能量，单位：焦耳（J）；热量是过程量，不能说“物体含有热量”，只能说“吸收/放出热量”。

4. 热传递：热量从高温物体传向低温物体的过程，传递的是能量，不是温度；热传递的条件：物体间存在温度差，直到温度相同（热平衡）为止。

5. 比热容（c）：单位质量的某种物质，温度升高（或降低）1℃所吸收（或放出）的热量，单位：J/(kg·℃)；比热容是物质的特性，与物质的种类、状态有关，与质量、温度变化无关。

6. 物态变化：物质由一种状态变为另一种状态的过程，包括熔化、凝固、汽化、液化、升华、凝华；物态变化过程中，温度可能不变（晶体熔化、凝固，液体沸腾），但内能一定变化（吸热或放热）。

7. 晶体与非晶体：晶体有固定的熔点和凝固点（熔化/凝固时温度不变），如冰、海波、金属；非晶体无固定熔点和凝固点（熔化时温度持续升高，凝固时温度持续降低），如玻璃、石蜡、松香。

2.2 核心公式（含适用条件）

1. 吸热/放热公式（热传递过程）：Q = cmΔt （适用条件：物体温度变化，且不发生物态变化；Q为热量，吸热时Q为正，放热时Q为负；c为比热容，m为质量，Δt为温度变化量，Δt = t末 - t初，单位℃）

2. 晶体熔化/凝固热量公式：Q = mL （适用条件：晶体发生熔化或凝固，温度保持不变；L为熔化热（或凝固热），单位J/kg，与物质种类有关）

3. 液体汽化热量公式：Q = mq （适用条件：液体发生汽化（蒸发或沸腾）；q为汽化热，单位J/kg，与物质种类有关）

4. 热力学第一定律：ΔU = Q + W （ΔU为内能变化量，Q为物体吸收的热量（Q正为吸热，Q负为放热），W为外界对物体做的功（W正为外界对物体做功，W负为物体对外界做功））

2.3 易错点辨析

1. 易错点1：温度≠内能，温度高的物体内能不一定大（还与质量、状态有关）；内能大的物体温度不一定高（如冰熔化时，内能增大但温度不变）。

2. 易错点2：热量是过程量，不能说“物体具有热量”，只能说“吸收/放出热量”；温度是状态量，可描述“物体的温度是多少”。

3. 易错点3：比热容是物质的特性，与质量、温度变化无关；如1kg水和10kg水的比热容相同，水升温10℃和降温10℃的比热容也相同。

4. 易错点4：蒸发和沸腾的区别：蒸发可在任何温度下发生，只在液体表面进行，缓慢；沸腾只能在沸点下发生，液体表面和内部同时进行，剧烈；沸点与气压有关，气压越高，沸点越高。

三、电磁学（核心模块）

3.1 基础概念

1. 电荷：自然界存在两种电荷，正电荷（用丝绸摩擦过的玻璃棒带正电）和负电荷（用毛皮摩擦过的橡胶棒带负电）；电荷间的作用规律：同种电荷相互排斥，异种电荷相互吸引。

2. 电荷量（Q）：表示电荷的多少，单位：库仑（C）；元电荷e = 1.6×10⁻¹⁹C，是最小的电荷量，任何带电体的电荷量都是e的整数倍。

3. 电流（I）：电荷的定向移动形成电流，单位：安培（A），1A = 1C/s；电流的方向：规定正电荷定向移动的方向为电流方向（与负电荷定向移动方向相反）；电源外部，电流从正极流向负极；电源内部，电流从负极流向正极。

4. 电压（U）：使电荷发生定向移动形成电流的原因，单位：伏特（V）；电源的作用是提供电压。

5. 电阻（R）：导体对电流的阻碍作用，单位：欧姆（Ω）；电阻是导体的特性，与导体的材料、长度、横截面积、温度有关（长度越长、横截面积越小，电阻越大；金属导体温度越高，电阻越大，半导体相反）。

6. 电路：由电源、用电器、开关、导线组成的闭合回路；电路的三种状态：通路（闭合，有电流）、断路（断开，无电流）、短路（电源正负极直接相连，电流过大，会损坏电源）。

7. 磁场：磁体周围存在的一种特殊物质，能对放入其中的磁体产生磁力作用；磁场的方向：规定小磁针静止时N极所指的方向为该点磁场方向。

8. 电流的磁效应：通电导体周围存在磁场（奥斯特实验）；通电螺线管的磁场与条形磁体相似，磁极方向由电流方向决定（安培定则）。

9. 电磁感应：闭合电路的一部分导体在磁场中做切割磁感线运动时，导体中会产生感应电流（法拉第实验）；感应电流的方向与导体运动方向、磁场方向有关；电磁感应是发电机的工作原理，将机械能转化为电能。

10. 通电导体在磁场中受力：通电导体在磁场中会受到磁力的作用（电动机的工作原理）；受力方向与电流方向、磁场方向有关（左手定则）；将电能转化为机械能。

3.2 核心公式（含适用条件）

1. 欧姆定律：I = U/R （适用条件：纯电阻电路（电能全部转化为内能）；I为电流，单位A；U为电压，单位V；R为电阻，单位Ω）；变形公式：U = IR、R = U/I（R与U、I无关，仅由导体自身特性决定）

2. 串并联电路规律：

   （1）串联电路：I总 = I1 = I2 = ... = In；U总 = U1 + U2 + ... + Un；R总 = R1 + R2 + ... + Rn

   （2）并联电路：I总 = I1 + I2 + ... + In；U总 = U1 = U2 = ... = Un；1/R总 = 1/R1 + 1/R2 + ... + 1/Rn（两个电阻并联：R总 = R1R2/(R1+R2)）

3. 电功公式：W = UIt （普适公式，W为电功，单位J；U为电压，I为电流，t为通电时间）；纯电阻电路推导式：W = I²Rt = U²t/R = Pt

4. 电功率公式：P = W/t = UI （普适公式，P为电功率，单位W）；纯电阻电路推导式：P = I²R = U²/R

5. 焦耳定律（电流的热效应）：Q = I²Rt （普适公式，Q为电热，单位J）；纯电阻电路中，Q = W（电能全部转化为内能）；非纯电阻电路中，Q < W（电能一部分转化为内能，一部分转化为其他形式的能，如电动机）

6. 电场强度公式：E = F/Q （E为电场强度，单位N/C；F为电荷在电场中受到的电场力，Q为试探电荷的电荷量；电场强度是矢量，方向与正电荷在该点受到的电场力方向一致）

7. 库仑定律：F = kQ1Q2/r² （适用条件：真空中的点电荷；F为库仑力，单位N；k为静电力常量，k=9.0×10⁹N·m²/C²；Q1、Q2为两个点电荷的电荷量；r为两个点电荷间的距离，单位m）

3.3 易错点辨析

1. 易错点1：电阻是导体的特性，与电压、电流无关；不能说“电阻与电压成正比，与电流成反比”（R=U/I仅为计算式，不是决定式）。

2. 易错点2：短路分为电源短路和用电器短路；电源短路（正负极直接相连）会损坏电源，绝对不允许；用电器短路（用导线直接连接用电器两端），用电器不工作，电路中电流变大。

3. 易错点3：欧姆定律仅适用于纯电阻电路，不适用于非纯电阻电路（如电动机、电风扇等，电能一部分转化为机械能，一部分转化为内能）。

4. 易错点4：电磁感应的条件：闭合电路、一部分导体、切割磁感线运动（三者缺一不可）；若导体不闭合，切割磁感线会产生感应电压，但无感应电流。

5. 易错点5：电流的磁效应（奥斯特实验）是“电生磁”，电磁感应（法拉第实验）是“磁生电”，两者原理相反，应用不同（发电机用电磁感应，电动机用电生磁）。

四、光学（基础模块）

4.1 基础概念

1. 光的传播：光在同种均匀介质中沿直线传播，传播速度：真空中c = 3.0×10⁸m/s，空气中近似等于c，水中为3/4c，玻璃中为2/3c。

2. 光的反射：光照射到两种介质的分界面时，一部分光会反射回原来的介质；反射定律：反射光线、入射光线、法线在同一平面内，反射光线和入射光线分居法线两侧，反射角等于入射角（反射角随入射角变化，两角始终相等）；反射分为镜面反射（光滑表面，如镜面）和漫反射（粗糙表面，如墙面），两者都遵循反射定律。

3. 光的折射：光从一种介质斜射入另一种介质时，传播方向发生偏折；折射定律：折射光线、入射光线、法线在同一平面内，折射光线和入射光线分居法线两侧；光从空气斜射入水或玻璃时，折射角小于入射角；光从水或玻璃斜射入空气时，折射角大于入射角；光垂直入射时，传播方向不变。

4. 凸透镜与凹透镜：凸透镜对光线有会聚作用（中间厚、边缘薄），凹透镜对光线有发散作用（中间薄、边缘厚）；凸透镜的焦点（F）：平行于主光轴的光线经凸透镜折射后，会聚在主光轴上的点；焦距（f）：焦点到光心的距离。

5. 凸透镜成像规律：根据物体到凸透镜的距离（物距u），成像的性质（正立/倒立、放大/缩小、实像/虚像）不同，应用于照相机、投影仪、放大镜等。

6. 光的色散：太阳光通过三棱镜后，分解为红、橙、黄、绿、蓝、靛、紫七种色光，说明白光是复色光；色光的三原色：红、绿、蓝（三种色光可以混合成各种色光）；颜料的三原色：红、黄、蓝。

4.2 核心公式与规律

1. 凸透镜成像规律（u为物距，f为焦距，v为像距）：

   （1）u > 2f：成倒立、缩小、实像；v = f~2f；应用：照相机、摄像机

   （2）u = 2f：成倒立、等大、实像；v = 2f；应用：测量焦距

   （3）f < u < 2f：成倒立、放大、实像；v > 2f；应用：投影仪、幻灯机

   （4）u = f：不成像（光线经凸透镜后平行射出）；应用：平行光源

   （5）u < f：成正立、放大、虚像；v > u；应用：放大镜

2. 凸透镜成像公式（高斯公式）：1/u + 1/v = 1/f （适用条件：薄凸透镜；u为物距（实物u为正），v为像距（实像v为正，虚像v为负），f为焦距（凸透镜f为正，凹透镜f为负））

3. 放大率公式：m = h像/h物 = |v|/u （m为放大率，h像为像的高度，h物为物体的高度；m>1时放大，m<1时缩小，m=1时等大）

4.3 易错点辨析

1. 易错点1：光的反射定律中，“反射角等于入射角”，不能说“入射角等于反射角”（入射角是原因，反射角是结果，因果关系不能颠倒）。

2. 易错点2：漫反射也遵循光的反射定律，只是因为表面粗糙，反射光线向各个方向发散，并非不遵循定律。

3. 易错点3：凸透镜对光线的“会聚作用”≠“会聚到一点”；凹透镜对光线的“发散作用”≠“发散开来就不会会聚”，只是推迟会聚或提前发散。

4. 易错点4：凸透镜成像中，实像都是倒立的，虚像都是正立的；实像可以用光屏承接，虚像不能用光屏承接（只能用眼睛直接观察）。

5. 易错点5：光的色散是光的折射现象，不是反射现象；色光的三原色与颜料的三原色不同，不能混淆。

五、声学（基础模块）

5.1 基础概念

1. 声音的产生：声音是由物体的振动产生的，振动停止，发声停止（但声音可能继续传播）；一切发声体都在振动（固体、液体、气体均可振动发声）。

2. 声音的传播：声音的传播需要介质（固体、液体、气体），真空不能传声；声音在不同介质中的传播速度不同，一般情况下：v固 > v液 > v气；15℃时，声音在空气中的传播速度为340m/s。

3. 声音的三个特性：音调、响度、音色。

（1）音调：由物体振动的频率决定，频率越高，音调越高；频率（f）：物体每秒振动的次数，单位：赫兹（Hz）；人耳能听到的声音频率范围：20Hz~20000Hz（超声波：f>20000Hz，次声波：f<20Hz）。

   （2）响度：由物体振动的振幅决定，振幅越大，响度越大；还与距离发声体的远近有关（距离越远，响度越小）；振幅：物体振动的最大幅度。

   （3）音色：由发声体的材料、结构决定，是区分不同发声体的依据（如不同人说话、不同乐器发声，音色不同）。

4. 声音的利用：传递信息（如听诊器、B超、回声定位）、传递能量（如超声波清洗、超声波碎石）。

5. 噪声：从物理学角度，噪声是由物体无规则振动产生的声音；从环境保护角度，凡是影响人们正常工作、学习、休息的声音都是噪声；噪声的单位：分贝（dB），0dB是人耳能听到的最微弱的声音，超过90dB会影响听力，超过150dB会造成听力损伤。

5.2 核心公式

1. 声音传播速度公式：v = s/t （v为传播速度，单位m/s；s为传播距离，单位m；t为传播时间，单位s）

2. 频率与周期的关系：f = 1/T （f为频率，单位Hz；T为周期，单位s，指物体振动一次所用的时间）

5.3 易错点辨析

1. 易错点1：振动停止，发声停止，但声音不一定停止传播（如振动停止后，已经发出的声音会继续在介质中传播）。

2. 易错点2：音调与响度无关，音调高的声音响度不一定大（如蚊子的叫声音调高、响度小；牛的叫声音调低、响度大）。

3. 易错点3：真空不能传声，因此太空中（真空环境）不能直接听到声音，需通过电磁波传递声音信号。

4. 易错点4：超声波和次声波人耳听不到，但它们也是声音，也由物体振动产生，也能传递信息和能量。

六、近代物理（基础拓展模块）

6.1 基础概念

1. 原子结构：原子由原子核和核外电子组成，原子核由质子和中子组成；质子带正电，电子带负电，中子不带电；原子呈电中性（质子数=电子数）。

2. 核能：原子核发生分裂（核裂变）或聚合（核聚变）时释放的能量；核裂变：重核分裂成轻核（如铀核裂变，应用于核电站、原子弹）；核聚变：轻核聚合成重核（如氢核聚变成氦核，应用于氢弹，太阳内部的能量来源）。

3. 爱因斯坦质能方程：E = mc² （E为能量，单位J；m为质量亏损，单位kg；c为真空中的光速，c=3.0×10⁸m/s；说明质量和能量可以相互转化）。

4. 光的波粒二象性：光既具有波动性（如光的干涉、衍射），又具有粒子性（如光电效应）；光子：光的基本粒子，具有能量和动量。

6.2 易错点辨析

1. 易错点1：核裂变和核聚变的区别：核裂变更易控制（核电站用核裂变），核聚变不可控（氢弹、太阳），且核聚变释放的能量比核裂变大得多。

2. 易错点2：质能方程中的m是“质量亏损”，不是物体的总质量；原子核分裂或聚合时，会出现质量亏损，亏损的质量转化为能量释放出来。

3. 易错点3：光的波粒二象性不是“光有时是波，有时是粒子”，而是光同时具有波动性和粒子性，不同情境下表现出不同的主要特性。
